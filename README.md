# WOLFVANE for Zed

A dark theme for [Zed](https://zed.dev), created by **icrmahin**.

WOLFVANE uses a restrained graphite interface with a deliberate syntax hierarchy: coral keywords, orange properties, purple functions, blue types and constants, light-blue strings, and muted italic comments. The theme is designed to keep code roles visually distinct without turning the editor into a high-saturation palette.

## Theme

- **Theme family:** WOLFVANE
- **Theme:** WOLFVANE Dark
- **Appearance:** Dark
- **Author:** icrmahin
- **Extension ID:** `wolfvane-theme`

## Install locally

1. Copy `themes/WOLFVANE.json` to your Zed themes directory:

   ```bash
   mkdir -p ~/.config/zed/themes
   cp themes/WOLFVANE.json ~/.config/zed/themes/WOLFVANE.json
   ```

2. Open Zed's Theme Selector with `Ctrl+K`, then `Ctrl+T`.
3. Select **WOLFVANE Dark**.

If the theme does not appear immediately, restart Zed and open the Theme Selector again.
